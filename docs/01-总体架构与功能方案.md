## 二、后台工作台（`gym-admin`）核心模块

### 模块 1：资产大盘 `/admin/dashboard`

- 动作 SKU 总数 / ⭐ 主力动作数 / 有视频·动图数 / 仅两帧数 / 精洗完成率（均可点击下钻进列表）
- 7 大部位 × 5 素材槽位覆盖率矩阵
- 最近任务流、待关联池数量、今日未命中提问数

### 模块 2：标准动作 SKU 库 `/admin/exercises` + `/admin/exercises/:id`

**列表页**
- 搜索：中文名 / 英文名 / 别名 / ID
- 筛选：部位 → 细分靶区、器械、动作模式、只看主力、素材状态、待复核标记
- 展示：缩略图、名称、别名胶囊、靶区标签、关节风险灯、5 槽位点亮状态

**单动作精修台（左右分栏）**
- 左：1:1 预览 + 5 槽位（`start` / `end` / `demo` / `highlight_video` / `tip`）  
  上传后自动裁剪压缩；替换 = 新建 `draft` + 发布后旧记录转 `archived`（可回滚）
- 右：分类标签 + 生物力学风险 + 4 步要领 + Cues + Mistakes  
  支持「✨ AI 一键补全教案」（生成草稿，人工审核后保存发布）

### 模块 3：批量上传与待关联池 `/admin/media-pool`

- 拖文件夹：按目录名匹配 `fdb_id` / 英文名，单文件失败不中断整批
- 待关联池：左侧未匹配预览，右侧候选动作相似度与 SKU ID，点绑定归位

### 模块 4：视频高光切片工作台 `/admin/video-studio`

- 双入口：本地 MP4 优先，粘贴链接（yt-dlp）为辅
- 流水线：入库 → Faster-Whisper 时间戳字幕 → LLM 定位高光 + 提炼干货 → FFmpeg 切片（SSE 进度）
- 人机审核：时间轴微调 + 字幕高亮跳转 + 确认绑定动作 SKU + 勾选入库的 Cues/Mistakes
- **产出是带声高光短视频，不是强转 GIF**

### 模块 5：AI Ops `/admin/ai-ops`

- 未命中收件箱：聚合 `debugtrace` 里 `ask` / `search` / `below_miss`
- Trace & Feedback：查看轨迹与点踩；支持一键把口语词绑定为动作别名，或送入评测 inbox

## 三、H5（`gym-coach/web`）新增与打通（后台稳定后实施）

**不新增底部一级 Tab。**

1. **动作库列表** `/exercises`  
   入口：训练 Tab 二级入口 + 今日选动作搜索  
   2 列网格 + 搜索（含别名）+ 筛选抽屉  
   默认排序：练过优先 → 主力动作 → 有素材优先

   三层降级：`demo` → `start/end` 无闪白切帧 → 显式占位  
   高光短视频入口 + 4 步要领 + Cues + Mistakes + 底部「加入今日训练」
3. **升级** `SwapExerciseModal` / `DraftCard`：加缩略图与详情预览
4. **升级** `CoachPage`：命中动作时气泡下挂图文/高光视频卡

## 四、数据契约

1. **`exercises` 主表（升级为新清洗结构）**
   - 保留原字段：`id`、`name_en`、`name_zh`、`body_part`、`equipment`、`target`、`secondary_muscles`、`category`、`description_en/zh`、`instructions_en/zh`、`image_start/end`、`fdb_id`、`muscle`、`roles`、`modality`、`gear`、`coach_core`
   - 新增清洗与管理列：`sub_region`、`movement_pattern`、`joint_stress`(JSON)、`cues_zh`(JSON)、`common_mistakes_zh`(JSON)、`is_valid_exercise`(bool)、`needs_review`(bool)、`updated_at`
2. **`exercise_media` 表**
   - 槽位 `role`: `start | end | demo | highlight_video | tip`
   - 状态 `status`: `draft | published | archived`（同动作同 role 仅一条 `published`）
3. **`exercise_aliases` 表**
   - 口语别名映射 `exercise_id` ↔ `alias`，状态 `draft | published`
4. **`media_unmatched_pool` 表**（A3 阶段建）
   - 批量上传未自动匹配的文件池
5. **`admin_tasks` 表**（A4 阶段建）
   - 异步流水线任务状态与进度
