# 07 · 计划模板后台配置台（工单）

> 配套后端 / H5 工单：`gym-coach/docs/plan/计划模板模块-实现工单.md`。
> 本文件只写后台 `gym-admin` 这一侧要做的配置界面与接口封装；表结构、展开规则、H5 页面见那份主工单。

## 1. 要做什么

在后台新增「计划模板」模块，运营可配置两类计划：
- **框架型 `framework`**：三 / 四分化，只定训练日部位、槽位角色、组次区间，动作留槽位待填；
- **成品型 `fixed`**：动作 / 组数 / 次数 / 顺序锁定（如运动员计划）。

## 2. 导航与路由

- `src/components/AdminShell.tsx` 的 `NAV` 增加：`{ to: '/plans', label: '计划模板' }`。
- `src/App.tsx` 挂：`/plans`（列表）、`/plans/:id`（详情编排）。

## 3. 列表页 `PlansPage`

- 表格 / 卡片列：标题、署名、类型标签（框架 / 成品）、每周天数、单次时长、部位标签、上下架开关、排序。
- 操作：新建、编辑、删除、上下架切换。
- 数据走 `GET /api/admin/plans`。

## 4. 详情编排页 `PlanDetailPage`

### 4.1 主信息
标题、副标题、署名 `author`、卡片角标 `badge_label`、类型、难度、每周天数、时长区间（`minutes_min`/`minutes_max`）、部位标签、分化短句 `split_summary`、器械标签（约定枚举见主工单）、简介、封面图、排序、上下架。

### 4.2 板块编排（左）
- 板块列表：序号、标题、部位、时长区间、封面、备注；支持增删、拖拽排序。
- 接口：`POST /api/admin/plans/{id}/blocks`、`PUT /api/admin/plan-blocks/{block_id}`、`DELETE /api/admin/plan-blocks/{block_id}`。

### 4.3 动作行编排（右，选中板块）
表格列：动作（复用现有动作搜索选择器）、角色、锁定级别、正式组数、次数、热身组数 `warmup_sets`、备选动作、备注。

- 角色 `role`：`main` / `assist` / `isolation` / `warmup`（独立热身动作）。
- 锁定级别 `lock_level`：`fixed` / `slot`。
- 接口：`POST /api/admin/plan-blocks/{block_id}/exercises`、`PUT /api/admin/plan-exercises/{ex_id}`、`DELETE /api/admin/plan-exercises/{ex_id}`。

### 4.4 封面图
落盘 `static/plans/{template_id}/`，**横向等比压缩**（勿复用动作库 1:1 正方形裁剪）。URL 存 `cover_url`。

## 5. 动作槽位角色（联动小改）

- 动作 SKU 编辑台补一组角色勾选，写入 **`Exercise.slot_roles`**（勿改 `roles` 肌群列表）。
- 框架型检索按 `muscle + slot_roles` 过滤。

## 6. 接口封装（`src/lib/api.ts`）

参照现有 `fetchExercises / fetchExerciseDetail` 写法，补：

- `fetchAdminPlans(query)`
- `createAdminPlan(payload)` / `updateAdminPlan(id, payload)` / `deleteAdminPlan(id)`
- `createPlanBlock(planId, payload)` / `updatePlanBlock(blockId, payload)` / `deletePlanBlock(blockId)`
- `createPlanExercise(blockId, payload)` / `updatePlanExercise(exId, payload)` / `deletePlanExercise(exId)`

类型与后端 `PlanTemplate / PlanBlock / PlanExercise` 字段一一对应（字段清单见主工单 §2）。

## 7. 验收

- 新建模板 → 编排板块与动作行 → 上传封面 → 上下架，刷新后持久。
- 成品型动作行锁定动作与组次；框架型可留空槽位。
- 删除模板级联清理板块与动作行。
- 后台现有动作库 / 媒体池页面无回归。
