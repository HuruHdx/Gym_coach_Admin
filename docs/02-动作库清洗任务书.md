# GymCoach 动作库结构化清洗任务书

> 输入：`gym-coach/api/assets/opengym/opengym_exercises_with_media.json`（5632）  
> 输出：`opengym_exercises_enriched.json` + `cleaning_report.md`  
> 原则：**不删不改** `id` / `name_en` / `fdb_id` / `image_*`；只新增与可覆盖修正字段。

---

## 标准枚举

### muscle → sub_region

| muscle | sub_region |
|---|---|
| 胸 | 上胸 / 中胸 / 下胸 / 胸中缝/内侧 / 胸部整体 |
| 背 | 背阔肌/背宽 / 中上背/背厚 / 下背/竖脊肌 / 斜方肌 |
| 肩 | 肩前束 / 肩中束 / 肩后束 / 肩袖/稳定 / 肩部整体 |
| 腿 | 股四头肌(前侧) / 腘绳肌(后侧) / 臀部 / 内收/外展肌 / 小腿 / 腿部整体 |
| 臂 | 肱二头肌 / 肱三头肌 / 前臂 |
| 核心 | 上腹/腹直肌 / 下腹 / 腹斜肌(侧腹) / 核心抗旋/稳定 |
| 全身 | 心肺有氧 / 全身爆发/HIIT / 全身拉伸/灵活 |

### 其他枚举

- `movement_pattern`：水平推 / 垂直推 / 水平拉 / 垂直拉 / 膝主导(蹲) / 髋主导(铰链) / 肘屈伸(弯举/臂屈伸) / 肩孤立(平举) / 核心卷曲/稳定 / 全身心肺/综合 / 拉伸/灵活
- `gear`：器械 / 自由重量 / 绳索 / 自重
- `modality`：抗阻 / 有氧 / HIIT / 灵活性
- `joint_stress.*`：low / medium / high（键：waist / knee / shoulder / wrist / elbow）

---

## 两阶段

### 阶段 1 · 规则脚本（全量 5632）

1. `is_valid_exercise`：过滤纯解剖名词条目
2. 推导 `muscle` / `sub_region` / `movement_pattern` / `roles` / `gear` / `modality` / 基础 `joint_stress`
3. 标记 `coach_core`（约 200~300 条健身房主力）
4. 保留原字段；写出 enriched JSON 初稿

### 阶段 2 · LLM 精洗（仅 `coach_core=true`）

对每条主力动作补齐/覆盖：

- `name_zh`（地道化修正）
- `aliases`（3~5 个口语俗称）
- `sub_region`（校准）
- `instructions_zh`（4 步教练口吻）
- `cues_zh`（2 条发力提示）
- `common_mistakes_zh`（2 条代偿纠错）
- `joint_stress`（生物力学校准）

批大小建议 10~15；失败重试；合并回 enriched JSON。
