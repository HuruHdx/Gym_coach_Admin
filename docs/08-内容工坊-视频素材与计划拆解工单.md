## 1. 核心目标（一鱼两吃）

把博主视频（纯口播为主，如推日 / 练胸跟练）喂进后台，**审一次视频同时干完两件事**：
1. **产出训练计划模板**：既能一条视频出一套单部位跟练课（如《凯圣王·胸部轰炸》），也能一次丢 3 条视频直接合成一套多分化计划（如《谭成义·经典三分化》）。
2. **顺手升级动作库**：
   - 遇到库里没有的新动作 → 右栏 **「＋ 一键新建入库」**（填名字/部位/器械），自动把视频里截的那 3～6 秒压成**静音循环小 MP4 + 自动抽一帧清晰封面 JPG** 挂进新动作，不用另外找图。
   - 遇到库里已有的老动作（没图，或者你想换成这个博主更标准的示范） → 勾一下 **「用这段画面补/换动作库示范」**，发布计划时顺手把动作库升级掉。

## 3. 入库与批量合成流程

### 3.1 批量贴分享口令 + Cookie 免手动下载
- **支持整段分享文案直接粘贴**：多行文本框支持一次贴 1～10 条抖音/B站分享口令（如 `7.53 复制打开抖音看看【xxx】https://v.douyin.com/xxx/`），后端用正则提取全部 URL。
- **下载管线（`studio_downloader.py`）**：
  - B站 / YouTube / 通用直链走 `yt-dlp`；抖音走无水印解析适配器 + `yt-dlp` 兜底。
  - 右上角提供 **「平台 Cookie 配置」**（存入服务端本地配置文件，不进 Git），粘贴一次浏览器 Cookie 即可稳定拉高清流。
  - 若单条链接被强风控拦截，该任务标为 `needs_manual_upload`，点一下即可拖本地 MP4 顶替，不影响同批其他链接继续跑。

### 3.2 两种入库建课模式（在贴链接弹窗直接选）
1. **各自成课（默认）**：贴 5 条不同博主的单部位视频 → 生成 5 个独立任务，每个产出一套单板块跟练计划（如《XX胸部训练》）。
2. **多条合成一套分化计划**：
   - 例如一次贴入同一博主的「推日」「拉日」「腿日」3 条链接，勾选 **「合成为同一套计划」**，填写计划名（如《谭成义·三分化》）。
   - 后端创建 1 个父批次（`batch_id`）+ 3 个按顺序排列的子视频任务；全部跑完后**自动按输入顺序拼成 板块1 / 板块2 / 板块3**，合在同一个审核界面里切 Tab 审，点一次发布即上线整套三分化。
3. **跨周追更兜底（「并入已有计划」）**：
   - 审核台底部保留 **「并入已有计划模板」** 按钮：若博主这周只发了推日，下周才发拉日，拆完拉日后可直接作为新 `PlanBlock` 追加进上周那套计划里。

## 4. 解析、打分、新动作入库与小 MP4 生成规则

### 4.1 语音字幕与分段（针对口播视频优化）
- FFmpeg 提取音频 → Faster-Whisper 生成带秒级时间戳字幕稿。
- LLM 读取字幕稿切分：**热身段 / 正式训练段 / 收尾段**：
  - 热身具体动作（如弹力带肩外旋）落 `role="warmup"`；纯口头热身叮嘱写入 `PlanBlock.note`。
  - 正式动作抽取出：`spoken_name`（口语动作名）、`target_muscle`（单行目标肌群：胸/背/肩/腿/臂/核心）、`role`（main/assist/isolation）、`target_sets`、`target_reps`、`source_kind`（spoken/visual/missing）、`snippet`（起止秒数）。
  - **绝不写死他人重量到公开模板**；组次未提及时留空标红待补。

### 4.2 红绿打分分流与发布门禁
- **绿灯（高分免检）**：别名或标准名高置信命中动作库 SKU + 有明确组次 + 有对应时间段 → 默认折叠或排在下方，无需逐条点确认。
- **红灯（置顶必审）**：库内无此动作（未绑定 `exercise_id`）、低置信模糊匹配、或组次缺失。
- **硬性上架门禁**：草稿阶段允许保留未绑定动作行；但点击 **「发布上线」** 时，所有动作行**必须已绑定有效 `exercise_id`**（未绑定行点右侧 **「＋ 一键新建 SKU」**，弹窗填 `中文名 + 主肌群 + 器械 + 槽位角色`，确认后自动建库、把原口语名写入 `exercise_aliases` 并完成回绑）。

### 4.3 弃用 `.gif`，统一产出「静音循环小 MP4 + 自动抽帧封面 JPG」
选中动作的 3～6s 示范区间 `[start, end]` 后，后端一次执行两条极速 FFmpeg 命令，**无需人工单独截封面图**：

1. **生成无声循环小 MP4**（体积 300～600KB，画质清晰，手机端静音自动播不抢耳机音乐）：
   ```bash
   ffmpeg -y -ss {start} -t {duration} -i input.mp4 \
     -an -vf "scale='min(540,iw)':-2,fps=24" \
     -c:v libx264 -preset fast -crf 26 -pix_fmt yuv420p \
     -movflags +faststart demo_loop.mp4
   ```
2. **自动抽中间帧作静态缩略图 JPG**（供列表页首屏秒开与 `<video poster>` 使用）：
   ```bash
   ffmpeg -y -ss {mid_time} -i input.mp4 \
     -frames:v 1 -vf "scale='min(540,iw)':-2" -q:v 3 cover_frame.jpg
   ```
- `exercise_media` 的 `role` 使用 `demo`（存小 MP4，`meta.mime="video/mp4"`）+ `start`（若原动作无起势图，顺手把抽帧 JPG 补进去）。

## 5. 自定义计划/板块背景图 + 零成本图床/对象存储方案

### 5.1 计划与板块自定义背景图（后台编辑能力补齐）
你要给「三分化」「五分化」「XXX胸部训练」配好看的自定义背景图，数据库字段其实**已经预留好了**（`PlanTemplate.cover_url` 和 `PlanBlock.cover_url`），只需在后台补齐两处顺手入口：
1. **计划主封面（`PlanTemplate.cover_url`）**：在 `/plans/:id` 和 `/studio` 右栏顶部支持 **① 本地拖图上传**、**② 直接粘贴外部图床 URL**、**③ 从内置预设质感底图库里点选一张**。
2. **训练日板块背景图（`PlanBlock.cover_url`）**：后台 `/plans/:id` 的左侧板块编辑区补上「上传板块图 / 贴外链」（例如给推日、拉日、腿日各配一张肌肉氛围图），H5 详情页渲染板块卡片时若 `block.cover_url` 存在则叠一层暗角渐变背景。

### 5.2 不想花阿里云 OSS 的钱，市面上图床/存储推荐哪个？

直接给结论：**千万别用野鸡免费公共图床（如路过图床、免费版 SM.MS、Imgur）**——防盗链随时变卦、国内访问抽风、还不支持放小 MP4 视频，哪天跑路图全裂。

**最推荐方案（按省心 + 零成本排）：**

| 排名 | 方案 | 免费额度 | 优点 | 适合阶段 |
|---|---|---|---|---|
| **首选 ⭐** | **Cloudflare R2**（兼容 S3 对象存储） | **每月 10GB 存储 + 1000万次读取 + 免流量费（0 出口带宽费！）** | 10GB 够存 **2万张高清背景图 或 2万条动作小MP4**；图片和视频通吃；绑一个自己的二级域名（如 `cdn.你的域名.com`）国内直连稳且全免费 | 个人开发到几千用户都 **0 元** |
| **备选 2** | **七牛云 Kodo / 又拍云（免费额度）** | 七牛实名送 **10GB 标准存储**（需绑自有备案域名走 HTTPS 回源注意流量包） | 国内节点速度极快 | 已有国内备案域名时可用 |
| **开发期零配置** | **直接存服务器本机 `/static/` + 支持外链混用** | 取决于服务器硬盘（几百张背景图才不到 100MB） | 现在代码**已经写好了**（`media_url()` 天然同时认 `/static/...` 和 `https://...`） | 本地/单机部署阶段一分钱不花 |

### 5.3 怎么在项目里丝滑接入（本地 & R2 双模存储适配器，改 1 个文件全通）

不需要重构任何表结构（现有的 `cover_url`、`exercise_media.url` 全是存字符串 URL，且 `media_url()` 已经兼容 `https://` 开头的外链！）。

在后端 `gym-coach/api/app/services/storage.py` 封装一个统一的 **`save_public_asset(data: bytes, key: str, content_type: str) -> str`**：

```python
# api/app/services/storage.py 思路示意
# .env 不配 R2 时自动存本地 /static/；配了 R2 自动传云端返回 https://cdn.xxx.com/...
#
# 新增环境变量（可选，不填就走本地磁盘）：
# STORAGE_BACKEND=local          # local | s3
# S3_ENDPOINT_URL=https://<accountid>.r2.cloudflarestorage.com
# S3_ACCESS_KEY_ID=...
# S3_SECRET_ACCESS_KEY=...
# S3_BUCKET_NAME=gym-assets
# S3_PUBLIC_BASE_URL=https://cdn.yourdomain.com   (或 R2 公开 r2.dev 域名)
```

- **怎么用**：
  1. 装一个 `boto3`（Cloudflare R2、七牛、阿里云 OSS、腾讯云 COS **全兼容同一套 S3 协议**，以后换任何一家只改 `.env` 四行配置，一行代码不用动）。
  2. `admin_plans.upload_plan_cover`、`admin_editor` 上传动作素材、以及 `studio` 导出的小 MP4/抽帧封面，统一调用 `save_public_asset(...)` 拿到返回的 URL 写入数据库。
  3. 同时保留后台输入框**直接粘贴任意 `https://...` 图片链接**写入 `cover_url` 的能力——你想临时从网上拷张图贴进去也能秒生效。

## 7. 后端接口清单（挂载 `/api/admin`）

- **配置与入库**：
  - `PUT /api/admin/studio/cookies`：保存 B站/抖音下载用 Cookie。
  - `POST /api/admin/studio/ingest-batch`：批量提交口令文本（自动提取多条 URL）或上传文件；支持参数 `merge_into_one_plan: bool`、`plan_title: str?`、`mode`。立即返回任务列表，后台异步队列执行。
  - `POST /api/admin/studio/tasks/{task_id}/upload-fallback`：某条链接下载失败时，补传本地 MP4 继续流水线。
- **查询与预览切片**：
  - `GET /api/admin/studio/tasks`：左栏队列状态轮询 / SSE。
  - `GET /api/admin/studio/tasks/{task_id}`：获取视频播放地址、字幕稿、解析出的动作行草稿与红绿打分。
  - `POST /api/admin/studio/preview-clip`：传入 `{task_id, start, end}`，秒切预览小 MP4 + 抽帧封面。
- **一键建 SKU 与确认发布**：
  - `POST /api/admin/studio/quick-create-exercise`：右栏红灯动作一键新建动作 SKU（含写入口语别名 + 挂载当前切片小 MP4 和封面图）。
  - `POST /api/admin/studio/confirm-plan`：提交审核后的板块与动作行（支持新建模板 **或** `append_to_plan_id` 并入已有模板；对勾选了「补/换动作库示范」的行同步写入 `exercise_media` 并自动发布）。
- **封面图增强**：
  - `POST /api/admin/plan-blocks/{block_id}/cover`：上传板块自定义背景图（走统一 `storage.save_public_asset`）。
  - `PUT /api/admin/plans/{id}` / `PUT /api/admin/plan-blocks/{block_id}`：已支持直接传 `cover_url: "https://..."` 外链，前端补齐输入框即可。

## 8. 建议开发顺序（给 AI 按步执行）

1. **Step 1（存储底座 + 自定义背景图）**：写好 `storage.py`（本地 `/static` + Cloudflare R2 S3 双模）→ 后台计划页与板块编辑补齐「上传背景图 + 粘贴图床外链」→ H5 板块卡支持展示 `block.cover_url`。
2. **Step 2（下载 + 字幕 + 切片底座）**：实现分享口令提取、`yt-dlp`/Cookie 下载队列、Faster-Whisper 时间戳字幕、FFmpeg 静音小 MP4 + 自动抽帧 JPG。
3. **Step 3（LLM 拆计划 + 红绿打分）**：口播切分段、抽动作与组次、匹配动作库打分、支持多链接 `batch_id` 自动合成为多板块草稿。
4. **Step 4（前端 `/studio` 一屏三栏工作台）**：左队列 + 中视频字幕联动拖选条 + 右一体化审核（红灯置顶、一键新建 SKU、顺手勾换动作库示范、一键发布/并入已有计划）。
