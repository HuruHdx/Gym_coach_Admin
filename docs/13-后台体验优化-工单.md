# 13 · 后台体验优化 · 实现工单

> 来源：2026-11-24 工坊 / 动作库 / 计划详情使用反馈整理。
> 口径：界面绑定与要领写库的产品规则仍以 `12-内容工坊-方案A-绑定与要领拆分.md` 为准；本工单只列**体验问题、根因和改造点**，不改 12 已定的两层拆分边界（草稿绑定 / 抽屉写库）。
> 行号为讨论时定位用，实现时以函数名 / 组件名为准。

## 1. 原始反馈（问题复述）

> 以下为使用后台时提出的原始问题，按场景分组；每条对应后文工单小节，便于核对有没有漏项。

### 1.1 工坊 · 识别与选区

1. **语音转字幕识别不准**，目前靠人工审核机制兜底。
2. **长视频截几秒片段很难操作**：上传 20 多分钟的视频，想截取几秒的选区不好拖；加了下方微调轴之后，上面总览选完区域大小被固定，只能在固定大小下一块块往后挪，不能像之前那样随意拖动。
3. **点动作清单定位画面偏早**：点「高位下拉」跳过去，画面里教练还在说"接下来我们……这个动作是高位下拉"，不是动作刚做起来的时刻，提前了几秒。

### 1.2 动作绑定 · 详情

4. **改名字段联动乱**：详情里改上面的文字，下面的名称跟着改。
5. **下拉框识别不准，且会重复 / 重复新建**：新建过「反握下拉」后没点最终保存就刷新页面，重新进这个动作详情，下拉里出现了刚新建的动作，同一个名字展示两遍，而且还能再新建一条。
6. **要点 / 易错对比看着乱、看不懂**：一会儿一句话打个标签「易错点 XXX」，一会儿又一个「新增」标签；原库里的描述和这次新增的差不多；底部"保留 / 覆盖"选项不知道什么意思；最下面一行"采纳最新 XXX、覆盖 XXX"单选云里雾里，不知道选了会怎样。

### 1.3 示范素材

7. **示范素材串成旧计划的内容**：之前在另一个计划里入库过同一个动作，这次想用当前视频的片段生成示范，点生成后，工作区展示的却是之前那个计划留下的旧图 / 旧示范。

### 1.4 计划详情

8. **计划详情填写项一脸懵**：很多字段不知道怎么设置、填了干什么；只想填 H5 用得到的内容：背景图、标签、标题；副标题前端可能还展示不出来；来源、工坊任务这类内部字段不该出现在编辑区。

### 1.5 总体感受

9. 动作库现在很多地方不规范，操作时一会儿改重复、一会儿改坏。

### 1.6 讨论中已明确的取向

- 不加热词喂识别模型、不做字幕评测集（评测只服务 H5 的 AI 功能）；维持人工审核方案，能微调减少审核压力即可；
- 要领一般认可就替换，合并 / 追加的场景不多；
- 对比表不打行内标签；要点 / 易错用分组小标题区分（类型系统已知道，人不用填）；
- 计划详情只做字段显隐和分组，不在现有 UI 上做大改。

### 1.7 问题与工单小节对照

| 原始问题 | 对应小节 |
|---|---|
| 1 字幕识别不准 | §2 明确不做（维持审核链路） |
| 2 总览选区固定大小、不能随意拖 | P1-3 选区重置入口 |
| 3 定位画面偏早几秒 | P1-2 锚点偏移 |
| 4 改名字段联动乱 | P0-2 绑定解联动 |
| 5 下拉重复、可重复新建 | P0-2 查重 / 去重 |
| 6 要点易错对比乱、选项看不懂 | P1-1 对比简化 |
| 7 串旧计划示范素材 | P0-1 素材串图 bug |
| 8 计划详情字段看不懂 | P2 字段显隐与分组 |
| 9 动作库不规范、改重复改坏 | P0-2 + 全工单收口 |

## 2. 范围与明确不做

**本次要做**：素材串图 bug 排查修复、绑定去重与解联动、要领对比简化、锚点偏移修正、选区重置入口、计划详情字段显隐。

**明确不做（不要顺手加）**：

- 识别模型热词喂入、字幕专用评测集；评测体系只服务 H5 的 AI 功能；
- 字幕纠错维持现有人工审核链路（清单改名 → 绑库 → 旧名进别名）；
- 要领语义合并 / 自动润色去重；
- 库内要领「还原」入口；
- GIF 产物（现状为静音循环 MP4 + 首帧 JPG，保持不变）；
- 计划详情页结构重排、换肤；只在现有外壳 / 栅格 / 控件上做字段显隐与分组。

## P0 · 数据正确性（先止血）

### P0-1 示范素材串成旧计划的图 / 视频（bug）· **已落地**

**现象**：同一 SKU 库里已有旧博主示范 → 新计划视频重切 → 工作台仍显示旧图/旧示范。

**已改**

- 后端 `attach_demo_now` 支持 `row_id`，优先按行写回 `demo_url / demo_cover_url`（避免同 SKU 多行串写）；
- `_hydrate_demo_covers` 仅在 clipped 且 **demo、cover 都缺** 时回填 SKU 封面（有本次 `demo_url` 不再用库内旧图顶）；
- 前端切片成功后 **钉住** 本次返回 URL（`clipPins`），轮询 `mergeClipMeta` 不得用旧缓存盖住；
- `onAttachDemoNow` 传 `row_id`，用 `draftRef` 写草稿，预览带 cache-bust；
- 产物条标注 `本次 ·` / `库内 ·`。

**验收**

- 绑已有旧示范的 SKU，本次重切后卡片与预览只显示本次片段；
- 轮询 / 切任务再回来，本次素材不被旧封面顶替；
- 旧媒体 archived，不出现两条 published demo。

---

### P0-2 绑定去重 / 解联动 · **已落地（前端）**

**现象**：同名可重复新建；抽屉「视频里叫 / 库里动作」双栏 + 改名联动搜框，像双向改名。

**已改**（口径已回写 `12` / `04` §7；规则 `ui-copy.mdc`）

1. 抽屉头部：**一个可改动作名**，无说明词；改名只存草稿，并作为下方库列表筛词；不自动展开、不改库名。
2. 下方 **库动作** 列表：候选 + 搜库相似；同 id 去重；同名不同 id 用部位/器械/编号区分；短按钮「重选 / 新建 / 收起」。
3. **新建前查重**：名字/别名命中则确认直接绑定，不静默再建。
4. **同步库名** 独立按钮 + 确认；**移除** 短词。
5. 落库时机：保持点新建立刻落库（A）+ 查重挡住大部分重复。

**验收**

- 抽屉无「视频里叫」等讲解文案；按钮为短词；
- 改名后下方列表按新名筛选，且不改库名；
- 已有同名时新建会先问是否直接绑定。

## P1 · 交互减负

### P1-1 要领 / 易错对比简化 · **已落地（前端）**

**原状**：表格逐条下拉 + 底部全局三态耦合；格子里叠「易错」「库无·进要点」等标签。

**已改**（`StudioPage.tsx` 抽屉 + `StudioPage.css`；口径已回写 `12`）

1. **顶部**：「一键替换」（有视频句→换掉/新增；库里独有仍保留）；
2. **分组**：`要点` / `易错` 两段小标题，不打行内类型标签；
3. **每行**：换掉 / 保留 / 新增；
4. **去掉**全局三态（按上面的换 / 只加不换 / 不入库）；
5. **汇总**随逐行选择重算；写入唯一按钮「保存编辑」（`cue_mode=replace`，按 relation 落库）；
6. 历史折叠标题改为「上次被换掉的旧版本，仅供查看」，按要点/易错分组只读。

**验收**

- 抽屉无全局三态、无行内类型长标签；
- 要点 / 易错分段可见；一键全换 + 逐行可改；
- 不点写入库内不变；写入后旧版进 `cues_library_backup`。

### P1-2 锚点偏移：点清单画面偏早

**根因**

锚点取 `spoken_at`（教练开口报动作名的时刻）；草稿 snippet 默认 `start = spoken_at`、`end = spoken_at + 5s`。口播介绍通常早于正式动作 1～3 秒，所以点行跳进去看到的是介绍句，不是动作开始。

涉及：前端 `anchorOf` / `focusRow` / `seekTo`；后端拆课输出 `spoken_at`、`snippet`（`studio_service.py` 拆课段，prompt 口径见注释「spoken_at = 正式讲/做该动作时的字幕秒数，不是示范画面逐帧起点」）。

**改造方案**

1. 后端拆课区分两个时刻：**报名字时刻**（spoken_at）与**首 rep 时刻**（新增 `rep_start`，取不到可空）；
2. 前端点行优先跳到 `rep_start`；没有 `rep_start` 再回退 `spoken_at` 加规则小偏移；
3. 默认选区长度按动作类型给 4～6 秒，不再固定口播 +5s；
4. 字幕句点击定位已有，保留不动。

**验收**

- 点动作行，画面落在正式做动作的起点附近，而不是介绍句；
- 无 `rep_start` 的旧草稿回退行为不报错；
- 轴上锚点标记与跳转时刻口径一致。

### P1-3 选区总览：加重置入口，减少误挪动 · **已落地**

**已改**（`StudioPage.tsx` / `StudioPage.css`）

1. 总览标题旁「重置选区」：清空选区与微调窗，再拖即为全新自由选区；
2. 短选区整段挪动命中从约 22px 收窄到约 10px，减少误触；
3. ≥56px 仍可在总览拖两端；短选区精修仍走微调轴。

**验收**

- 重置后可从零拖新选区，无旧长度/位置残留；
- 短选区误挪明显减少；±0.5s / ±5s 步进保留。

## P2 · 计划详情字段显隐 + H5 卡面统一 · **已落地**

**口径**

- `scene_tag` = 计划库**大分组**（热门计划 / 女性专项 / 新手入门 / 进阶强化 / 居家训练 / 增肌专项 / 减脂塑形 / 博主同款），**不是**三分化/五分化。
- 分化写进标题或 `split_summary`（如 `胸 · 背 · 腿`）。
- 列表卡不贴所属分类小标；分组标题已经说明分类。

**后台**（`PlanDetailPage`）

- 主区：封面、标题、分类、难度、简介、部位、器械、发布；
- 次要：角标、分化短句、时长、每周天数；
- 高级折叠：类型、排序；
- 隐藏：副标题、署名（仍随保存透传，不删库字段）。
- 工坊「计划信息」分类下拉同步新人词表。

**H5**

- 计划库 / 训练 tab 卡：大封面 + 标题 + 一行短信息（部位或分化短句）；无分类角标；
- 计划库按 `scene_tag` 分栏；
- 详情：更大头图；头图上最多难度/角标；简介 + 部位/器械 + 板块列表。

**验收**

- 后台主区能填完 H5 常用字段；高级可折叠；
- H5 列表像参考图：栏是分类、卡面干净；详情比列表信息更多、头图更大。
