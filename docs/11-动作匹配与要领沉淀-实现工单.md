## 产品共识（仍有效部分）

1. **大类 vs 小词**
   - 大类（自由重量 / 器械 / 绳索 / 自重）→ 只管动作库 SKU 归类、排课筛选。
   - 小词（杠铃 / 哑铃 / 上斜 / 罗马尼亚…）→ 只管听名匹配，从**名字**里抠，跨胸背腿肩通用。
2. **含糊名禁止自作主张**
   只说「深蹲 / 卧推 / 硬拉」→ 列出库内候选让人选，不得偷偷钉成「杠铃××」。
3. **打分统一 0～100**
   草稿里 `match_confidence = score/100` 仅兼容旧字段，不作为主判断口径。
4. **热身**照抽、`role=warmup`，不填假的 3×8-12；配课主项池排除纯 warmup。
5. **组次照抽但不入库**（`Exercise` 表无 sets/reps 列）。

## 阈值与灯色（**与 12 联动，见 12 §3.1**）

| 分 | 行为 |
|---|---|
| ≥90 且非含糊 | 可预填主命中；组次齐或热身 → 绿 |
| 55～89 | 只出候选，等人点选（黄） |
| <55 | 当新动作，候选可空（红） |

**点选候选后立刻转绿**：草稿有 `exercise_id` 且无其他缺失即为绿，不再「待确认」。
绿/黄/红只反映「能否发布」，不反映「是否已写要领」——要领写没写由详情页负责，与灯色无关。
