> 2026-11-19。本目录 4 张图 + 本文。产品定稿见项目内 `docs/12-内容工坊-方案A-绑定与要领拆分.md`，**图文口径以 12 为准**。

## 一、为什么你觉得乱

不是审美问题，是**功能没有归属**。看代码就知道：

| 文件 | 大小 | 问题 |
|---|---|---|
| `src/pages/StudioPage.tsx` | 95.8 KB / 2400+ 行 | 所有功能塞在一个页面 |
| `src/pages/StudioPage.css` | 34.7 KB | 所有样式塞在一个文件 |

具体表现：

1. **一屏混了四类东西**：任务队列（列表）、视频操作（提取）、动作清单（数据编辑）、配置（Cookie / LLM）。
2. **右栏标题里塞了工具栏**（`renderRightTools` 放在 `col-head` 里）——工具没有归属，用户不知道这按钮管什么。
3. **动作卡什么都干**：绑定、改名、比对要领、决定写不写库，五个动作挤一张卡，按钮平级，点哪个生效都不清楚。
4. **按钮全是同级**：主操作、次操作、危险操作长得一样，没有主次。
5. **新功能只能挤**：封面、要点、字幕，实现时找不到位置，就往中栏和右栏里塞。

结果：**"哪里能点"和"哪里是配置"没有视觉区分**；更麻烦的是**"点了会改什么"看不出来**。

## 二、三条改造原则

### 原则 1：配置就地出现，不建集中设置页

**结论：不单独做"设置页"。** 配置放在**它被需要的那一刻**：

| 配置 | 放哪 | 为什么 |
|---|---|---|
| Cookie / 读哪个浏览器 | **新建任务弹窗**，链接下面 | 有时效、分平台，失效时你正在建任务 |
| 处理程度（标准 / 只转字幕 / 连素材） | 新建任务弹窗 | 是按这条视频定的，不是全局默认 |
| 封面比例 | 点「封面取首帧」时弹小面板 | 只作用于这一次操作 |
| 模型 / Prompt | **服务端 `config.py` + env**，不进界面 | 改一次要重启，做成 UI 反而要维护版本和权限 |
| 存储后端 / CDN 前缀 | **服务端 env**，界面最多显示一行只读状态 | 要装 boto3、填密钥、重启服务，表单做不完 |

判断标准一句话：**会影响所有任务、而且几乎不变的，写进服务端配置；有时效或按次定的，就地出现。**

### 原则 2：一个面板只干一件事，用职责标标出来

面板标题右侧加一个标签，让用户一眼知道这块是干嘛的：

| 标 | 含义 | 长什么样 |
|---|---|---|
| `只读` | 只能看，不能改 | 蓝灰，`#8fa0e8` |
| `操作区` | 能改数据 / 能框区间 | 主题绿 |
| `产出` | 会生成新文件 | 琥珀 |

### 原则 3：一个操作只贴一个入口 + 全屏唯一实心主按钮

- **一个操作只贴一个对象**：按钮必须挨着它改的那条东西。绑定按钮贴候选、写入按钮贴要领块、改名贴动作名。不许集中堆在卡片底部按钮条。
- **主操作**：`发布`，全屏唯一实心主题色。
- **次操作**：描边，行内出现。
- **危险操作**：红色，只在真要删的时候出现。

## 三、四张图

### `01-工作台-重构后.png` — 三栏职责

1. **三栏职责固定**：左=只读队列、中=操作区（视频 + 时间轴）、右=操作区（动作清单）。
2. **素材只有一个出口**：中栏的**选区操作条**（`截成示范段` / `封面取选区首帧`）。别处不重复。
3. **本次产出有地方看**：示范段 MP4 + 封面 JPG + 计划封面（人工上传，未设占位）。**不产 GIF。** 封面 URL 须写回草稿 `demo_cover_url`，刷新后缩略图不能丢成灰块「示范」。
4. 底部状态写人话：`2 个待绑定 · 1 个库外 / 修完才能发布`。队列：未点发布显示「可发布」，点过后显示「已发布」（不要停在「待审核」或别条任务的「转字幕 xx%」）。
5. 右栏动作清单头按钮文案用「重新拆动作」（按现有字幕用 AI 重识别清单），强调色描边，不用「LLM 重拆」。

### `02-新建任务-Cookie就地配置.png` — 配置跟着任务走

1. 平台自动识别：贴完链接直接认出 `B站 · BV1xx411c7mD`。
2. Cookie 就地管：`Cookie 未配 · 720P 可用` + `从浏览器读取`。过期了就在这里点。
3. 处理程度按这条视频算，选完记住上次。
4. 环境缺失前置拦住：`✓ yt-dlp ✓ faster-whisper ⚠ ffmpeg 未装`。

### `03-动作卡-候选确认.png` — **卡片只做绑定**

卡片里**只有一件事：这条口播对应库里的哪个动作。**

1. 头部：口播名 + `疑似已有`（**无改名按钮**；改名只在 04 抽屉）。
2. 候选 top3：同名 / 核心+器械 / 仅核心，百分制分数 + reason 标签。
3. **点一条即绑定**，选中态即生效；无 `就用这条 / 采纳` 二次确认。
4. 底部只有两个文字链：`搜库换个名字` · `库里确实没有，新建`。
5. **卡片内不再出现要领文本、对比表、三态、写入按钮、改名**——全部在抽屉（见 04）。

### `04-动作详情-右侧抽屉.png` — **要领在抽屉里写库**

工作台不变。点动作清单某一行 → 右侧滑出 558px 抽屉，盖住动作清单和半个视频区，左上任务队列仍可见（压暗）。**不跳页、不新增路由**，右上角 `×` 关闭即回工作台。

抽屉内自上而下：

1. **动作名 + 改名对齐叫法**（小描边按钮，改名时旧名进别名）。
2. **逐条对比表**：左列 `库里现在`（被换掉的加删除线、灰），右列 `这次视频`（带时间戳，新增项琥珀标签），最右 `处理`：换掉 / 新增。
3. **结论行**：`前两条说的是一回事，视频版更具体；第三条库里没有 → 换 2 条、加 1 条，库里变 3 条`
4. **三态（默认覆盖）**：`按上面的换` / `只加不换` / `不入库`
5. **唯一写入按钮**：`保存编辑`（描边强调，非实心），旁注 `不点只留在这次草稿，不会改动作库`；对比区顶部有 `一键替换`
6. **这段原话（只读）**：带时间戳的字幕原句，作为判断依据。
7. **历史要领（只读，折叠）**：覆盖前留档，不提供还原按钮。

> 示范素材的操作仍在中栏选区条上（`截成示范段` / `封面取首帧`），**不在抽屉里**。抽屉只管要领与改名。

## 五、B站下载失败：真正的原因（不是 Cookie）

### 5.1 根因

`api/app/services/studio_service.py` 的 `_download_url()` 里，Referer **写死成抖音**：

```python
"--referer",
"https://www.douyin.com/",
```

B站对 `playurl` 接口做 Referer 校验（防盗链）。带 `douyin.com` 的 Referer 请求 B站 → **403**。

然后错误被归类成这句：

```python
if "fresh cookies" in low or "http error 403" in low or "403: forbidden" in low:
    return "平台拒绝访问（需要新鲜 Cookie）。"
```

所以你看到的是"没 Cookie"，实际是**请求头不对**。这条错误归类把 90% 的 B站失败误导成 Cookie 问题。

### 5.2 修法（三行逻辑）

1. **Referer 按域名给**：`douyin.com` → 抖音；`bilibili.com` / `b23.tv` → `https://www.bilibili.com/`；`youtube.com` → 不传。
2. **先不带 Cookie 试一次**。B站公开视频不需要登录，能直接拿 480P / 720P。
3. **失败后再带 Cookie 重试**，而不是一开始就要 Cookie。

### 5.3 关于"浏览器里 Cookie 是乱码"

不是加密。B站 Cookie 是一长串字段（`buvid3` / `buvid4` / `b_nut` / `_uuid` / `bili_jct` / `SESSDATA` / `buvid_fp` …），其中 `buvid3`、`buvid4` 本身就是长编码串，`SESSDATA` 是 URL-encoded（带 `%2C`），看着像乱码。

**只需要 `SESSDATA`**（可选再带 `bili_jct`）。别手抄：优先 `--cookies-from-browser edge`（要完全退出浏览器），或扩展导出 `cookies.txt`，或干脆不配 Cookie 下 720P。

### 5.4 本机环境提醒

公司机 venv 里没装 `yt-dlp`，PATH 里没有 `ffmpeg`。链接下载在这台机器上必然报「未安装 yt-dlp」。要测这条链路回家那台测，或先 `pip install yt-dlp`。`ffmpeg` 装完要**重启 API 进程**。

## 六、建议的改法顺序（不要一次重构）

1. **先修 Referer + 错误归类**（后端，10 行内）。这一步不通，工坊没有输入。
2. **删掉设置弹窗，Cookie 搬到新建任务弹窗**。
3. **动作卡砍到只剩绑定**（把要领块整体移走，先删不加）。
4. **详情页接入要领对比表**（配对接口 + 三态 + 写入按钮）。
5. 合并中栏操作为选区操作条。
6. 最后再谈视觉细节。

第 1、2 步做完，"乱"的感觉会掉一半。第 3 步是关键——**不是把五个功能排整齐，是把四个功能搬走**。
